Brand orange, Pantone 151 C

Every shade below keeps 151C's hue and saturation and lowers only its lightness, measured in OKLCH, just far enough to reach a WCAG contrast target on one of the site's light backgrounds. The ratios in the table are computed on this page from the hex values.

We compared these for the docs site and chose none of them: the site uses 151C as is, for links and for inline code, and sets code heavier on a lighter chip instead. The last panel shows where we landed.
